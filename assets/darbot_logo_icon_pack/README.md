# Darbot Browser MCP Logo & Icon Pack — v3

This package updates the Darbot Browser MCP ghost mascot with the new segmented globe-and-lightning emblem while preserving the original neon ghost outline and browser visor.

## Primary assets

- `darbot-browser-mcp-logo-1024.png` — transparent 1024×1024 RGBA logo.
- `darbot-browser-mcp-logo.svg` — editable traced-vector version.
- `darbot-horizontal-banner-1500x500.png` — transparent horizontal banner.
- `icons/darbot.ico` — multi-resolution Windows icon.
- `icons/darbot-{size}px.png` — requested transparent icon sizes from 16 through 1024 px.

## Additional assets

- `icons/emblem/` — emblem-only icon set for very small UI surfaces.
- `source/` — 2048 and 4096 px transparent masters plus editable SVG sources.
- `banners/` — transparent, dark, and light 1500×500 banner variants.
- `web/` — favicon, Apple touch icon, Android icons, SVG favicon, and web manifest.
- `previews/` — light/dark compatibility and scale-reference sheets.

## Image processing

The supplied artwork was rebuilt with alpha-aware compositing, white-matte decontamination, color-fringe replacement, supersampled Lanczos resizing, and multi-resolution ICO generation. PNG files are RGBA/32-bit and preserve transparency.

## Brand palette

- Neon pink: `#FF19E3`
- Electric purple: `#A71FEF`
- Electric blue: `#2864F1`
- Cyan: `#2CE1E8`
- Dark navy: `#0F1419`

Banner typography is rendered into the PNGs; no font files are included.
